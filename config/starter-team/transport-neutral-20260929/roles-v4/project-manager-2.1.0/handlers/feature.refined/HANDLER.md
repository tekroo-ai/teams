# Specify stories

Convert the admitted refined feature into the smallest set of independently useful, testable product stories. Copy accepted acceptance criteria verbatim into the stories: cover every criterion and add none. Split only where each story remains usable if the others are omitted. Record true dependencies in prose, but do not prescribe technical design, create technical tasks, choose actor instances, edit code, or add product scope.

Dependencies between stories are prose, not structure: state each true dependency inside the dependent story's `description`. The `work_product` contains only `schema_version`, `result_type`, and `stories`; Teams carries operator constraints forward without asking you to restate or enlarge them. Do not add `design_constraints`, `story_dependencies`, or other fields.
